STAR STORES — WEBSITE FILES
============================

What's inside
--------------
index.html   The page itself
style.css    All styling / colours / layout
script.js    The mobile menu and the small footer-year script

How to view it
---------------
Double-click index.html to open it in any web browser (Chrome, Edge,
Safari, etc.). An internet connection is needed only to load the map
at the bottom of the page and the two fonts — everything else works
offline.

How to put it online
----------------------
Upload all three files (index.html, style.css, script.js) to any web
hosting service, keeping them in the same folder together. Popular
low-cost/free options for a small business site include Hostinger,
GitHub Pages, and Netlify — any of them will work, just upload the
folder as-is.

Changing the phone number or address
--------------------------------------
Open index.html in any text editor and use Find & Replace:
  - "7044660620" → your number (also update the "tel:+91..." and
    "wa.me/91..." links the same way)
  - The address text appears in two places: the "Visit" section and
    the footer.
